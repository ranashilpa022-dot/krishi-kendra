# 🌾 Krishi Kendra Website

A mini-project website designed for a **Krishi Kendra (Agriculture Center)** to showcase agricultural products and services.  
This project demonstrates the use of **HTML, CSS, and JavaScript** to build a responsive and user-friendly website.  

---

## 🚀 Features
- 🛒 Product Section to display available items  
- ⚙️ Services Section highlighting offerings  
- 📞 Contact Page for user inquiries  
- 🎨 Responsive Design for desktop and mobile devices  
- 🌐 Hosted live using **GitHub Pages**

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Hosting:** GitHub Pages
